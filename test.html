Come collegare il tuo PDF

Istruzioni per inserire questo viewer sul tuo sito web

Per fare in modo che il libro carichi automaticamente il PDF situato nella repository del tuo sito web, modifica la variabile DEFAULT_PDF_URL all'interno del codice JavaScript:

// Nel blocco script in fondo alla pagina:
const DEFAULT_PDF_URL = './documenti/mio-libro.pdf';
Nota importante per i Server Web: Assicurati che il percorso del file PDF sia relativo alla pagina HTML o assoluto (es. /assets/pdf/libro.pdf). Il server deve consentire l'accesso HTTP GET al file.
